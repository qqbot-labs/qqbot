# QQ Agent 产品定义

QQ Agent 为个人普通 QQ 小号提供独立的中文管理台、好友互动、私人记忆、成长素材及 QQ 空间桥接，不与 QQ Whale 官方机器人混用账号或运行开关。

NapCat Core 固定 4.6.7，QQ 使用 3.2.16-32793；版本证明来自运行中组件和鉴权接口。人格由主人提供原文，不自动生成默认人格。QQ 与空间独立登录，连接在线与真实平台动作分别验收。

每日主动私聊、评论、发布、点赞、总发送、模型调用、Token、费用及搜索配额默认 `0`，表示不限制；可选正数配额由用户设置，不附加最大值。主动冷却默认 `0`；免打扰起止相同表示关闭。自主决策不设置每日一次闩锁；检查周期为独立调度参数。

会话、空间内容与日志保留天数为 `0` 时不自动删除。配置入口、校验和执行端对 `0` 的含义必须一致，不能保存后由其他阈值再次阻止。

人格、好友许可、退订、渠道开关、停止发送与暂停主动均由主人管理。取消业务额度不改变这些已有选择，不启用另一账号，不补发重启前的旧任务。未知发送结果不盲重试。

模型上下文、输出预算、超时、分页和批次参数可见、可调。组件不预设本项目的内存或进程数量天花板；实际硬件和第三方接口仍有能力边界。

保持私聊对象的记忆隔离，公开空间输出仅使用主人明确标为公开的素材。空间读取失败不能当作没有动态，首次读取建立历史基线。私有数据、凭据、Cookie 和原始平台响应不进入 Git。

部署前创建可靠的项目恢复点，并明确它是否为整机备份。验证涵盖 Python 引擎/适配器、空间桥接、管理台、真实模型与真实平台，未执行的验收单独列出。
