# QQBot 产品定义

QQBot 面向个人自用，包含 QQ Whale 陪伴机器人、它的私有管理台，以及独立的 QQ Agent / NapCat / QQ 空间栈。各栈的账号、人格、渠道启用状态和数据相互独立。

## 自然交流

日常回复像熟悉的 QQ 朋友接话，保留用户设置的人格与称呼。一句够了就停，不按字数、句数或消息条数凑回复，不固定附加追问、建议、总结或催休息。

独立意思用换行分开。普通回复与主动消息共用分条器，保留显式换行；较长的多句内容按句子分条，超长逗号串可在语义转折处分开。代码、列表、表格和引用保留结构。详细解释按问题需要讲完整。

分组字数与发送停顿属于可见的节奏参数，不截断正文。`chat-delivery.json` 的 `maxMessages=0` 不设置本地条数上限。QQ 平台的发送窗口、额度、消息长度和接口错误如实呈现，不伪造成功。

## 越聊越熟悉

真实入站原文独立归档，重启、压缩或换会话后仍可检索。归档字数和保留时间可取消限制。

主人明确表达的稳定偏好、个人事实、称呼、共同设定和关系约定通过 `persona_remember` 持续保存，普通聊天不必每次附带“记住”。档案按主题 `key` 更新，或用 `replace_id` 更正；当前值与旧版本历史分开。共同扮演设定标为 `setting`，不当作现实 `fact`。

撤销设定通过 `persona_forget` 执行，并保留撤销主题标记，避免从更早的聊天重新采用。用户明确重新设定该主题时可恢复采用。聊天原文的删除由 `memory_forget` 处理。临时情绪、猜测和机器人自行编造的背景不保存为稳定事实。

普通接话和主动关心都读取同一份当前档案及撤销主题。档案在管理台可查看和删除，不设条数或单条字数配额。

## 无默认业务配额

主动关心、表情包、发送、搜索、模型请求、Token、费用及成长不添加固定每日次数或不可关闭的冷却。保留可选配额的字段时，`0` 明确表示不限制，前后端含义一致；不另设隐藏上限或每日一次的决策闩锁。

闲置门槛、主动发送间隔、评估间隔设为 `0` 时不拦截；免打扰开始与结束相同时不限制时段。定时检查周期与业务次数额度分开。AI 可以根据话题与反馈选择暂不联系，不以固定次数代替判断。

数据告警阈值、备份保留份数和内容保留天数设为 `0` 时分别表示不设阈值、不自动删备份、不自动删内容。模型上下文、输出预算、网络超时、批次大小和实际平台协议参数明确展示，不冒充用户要求的业务配额。

## 部署与验收

线上配置、人格、凭据和聊天数据不进入公开仓库。安装目录补丁须固定上游版本、校验原始摘要、支持重复检查，并在启动前核验。升级插件后须重新验证补丁。

保留用户主动管理的渠道开关、好友权限、停止发送和独立账号选择。去除配额不会擅自启动另一套社交栈。未知发送结果不盲目重发；分条期间收到新消息时停止剩余主动内容，已发送部分独立记账并加入上下文。

验收分别记录自动化、真实模型、运行时对话、QQ 平台接受、客户端实际显示和长期运行，不能相互替代。独立 QQ Agent 的有效产品定义见 [QQ Agent PRD](../apps/qq-agent/docs/PRD.md)。
